# Elysia 1.1.0 coordinated release candidate

This candidate coordinates Elysia, neutral Codev Core, and the optional VS Code
adapter at 1.1.0. Product metadata does not assert that final artifacts have
been qualified or published. The original public 1.0.0 releases remain intact.

Changes carried forward include the installation-gated local Codev workroom;
one private Unix runtime shared by native clients; explicit account-bound
website pairing and revision-checked edit proposals; responsive rooms and
native minimum window sizing; and the shared sealed identity-photo pipeline.

The release correction updates product identities and exact package references
without changing API 1.0.0, Codev/broker/workspace protocol contracts, identity
schema, or memory schema. It adds precise mixed-family upgrade guidance and
retains browser protocol support for the previously qualified 1.0.0 Core.

See [compatibility and installation](INSTALL_UPDATE_ROLLBACK_UNINSTALL_v1.1.0.md)
and [qualification limits](KNOWN_ISSUES_v1.1.0.md). Exact public artifacts must
match publisher-signed release manifests; unsigned candidates are not stable
updates. Availability belongs to the canonical GitHub releases and Archive.
