## Non-negotiable production gates

Every worker/model must pass safety, licensing, provenance, resource stability, and consent. Unresolved gates result in `lab_only`, `disabled`, or `blocked`; silent promotion is forbidden. Generated image/video/audio artifacts receive provenance sidecars and synthetic/local-only truth. Central request/audit records use prompt/text/transcript hashes and compact outcomes, never raw prompts, source media, full transcripts, generated bytes, absolute private paths, or worker logs.

## Interface truth

Elysia Desktop keeps speech actions and the acknowledged Wan lab action inside the existing collapsed governed-worker section. Codev surfaces installed/live/lab/blocked truth and has typed API support, but does not duplicate Elysia as a processing backend or present production-generation controls. Disabled capabilities have explanations rather than fake buttons.

## Proof boundary

Focused source tests and disposable `/tmp` route proofs establish behavior for the tested profiles only. Manual Desktop and Codev interaction remains a release-review activity, not a basis for silently changing a gate. Full-suite failures that predate Chunk 5 are tracked separately from focused media-worker proof.
