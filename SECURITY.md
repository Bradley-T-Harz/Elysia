# Security

Do not place vulnerability details, credentials, private memory, personal data, signing material, or production secrets in a public issue. Report security concerns privately to the operator through the current support contact published at <https://elysiaecobotics.com/.well-known/security.txt>.

Include the affected version/profile, bounded reproduction steps, and impact without attaching real user data. No response-time or bounty promise is made here. Release support and security status are governed by the current Elysia release documentation.
